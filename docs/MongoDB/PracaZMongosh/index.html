Kolekcja - CR_D​

🟦

Jawne utworzenie kolekcji - CREATE​

db.createCollection("shop")

Automatyczne tworzenie kolekcji podczas dodawania dokumentu - CREATE​

db.users.insertOne({ name: "Jurek", age: 20 })

Wyświetlanie kolekcji w danej bazie - READ​

show collections

Usuwanie kolekcji - DELETE​

db.<nazwaKolekcji>.drop()

np. db.shop.drop()

Podsumowanie operacji na kolekcji i CRD​

OperacjaOpisKomenda
C — CreateJawne tworzenie nowej kolekcjidb.createCollection("nazwa")
R — ReadWyświetlenie listy kolekcji w bieżącej bazieshow collections
D — DeleteUsunięcie całej kolekcjidb.nazwa.drop()

Praca z dokumentami - CRUD​

OperacjaOpisKomenda (przykład)
C — CreateDodanie nowego dokumentudb.users.insertOne({ name: "Jurek", age: 20 })
R — ReadWyszukiwanie dokumentówdb.users.find({ age: { $gt: 18 } })
U — UpdateAktualizacja istniejącego dokumentudb.users.updateOne({ name: "Jurek" }, { $set: { age: 21 } })
D — DeleteUsuwanie dokumentówdb.users.deleteOne({ name: "Jurek" })

Przygotowanie bazy danych​

test> use trylogia
switched to db trylogia

trylogia> db.createCollection("bohaterowie")
{ ok: 1 }
trylogia>

CREATE - dodawanie dokumentów​

Dodanie jednego dokumentu​

db.bohaterowie.insertOne({ imie: "Andrzej Kmicic", powiesc: "Potop", rola: "bohater" })

Dodanie wielu dokumentów​

db.bohaterowie.insertMany([
{ imie: "Michał Wołodyjowski", powiesc: "Pan Wołodyjowski" },
{ imie: "Jan Skrzetuski", powiesc: "Ogniem i Mieczem" }
])

READ — odczyt dokumentów​

Odczyt wszystkich dokumentów​

db.bohaterowie.find()

Filtrowanie​

db.bohaterowie.find({powiesc:"Potop"})

Wyszukiwanie konkretnej postaci​

db.bohaterowie.find({imie:"Andrzej Kmicic"})

UPDATE - aktualizacja dokumentów​

Zmiana wartości istniejącego pola​

db.bohaterowie.updateOne({imie:"Andrzej Kmicic"}, {$set: {imie:"ANDRZEJ KMICIC"}})

Dodanie nowego pola do dokumentu​

dla wszystkich dokumentów db.bohaterowie.updateMany({}, {$set: {epoka: "Barok"}})

dla wybranych dokumentów db.bohaterowie.updateMany({imie:'Michał Wołodyjowski'}, {$set: {czyLubiany:true}})

DELETE - usuwanie dokumentu​

db.bohaterowie.deleteOne({ imie: "Michał Wołodyjowski" })

db.bohaterowie.deleteMany({epoka:"Barok"})
