Metoda GET

Czym jest metoda GET w ExpressJS?​

  • Metoda GET to sposób pobierania danych z serwera.
  • Gdy przeglądarka (lub klient HTTP) wysyła żądanie GET, mówi do serwera:
    • „Hej, pokaż mi te dane, ale niczego nie zmieniaj po swojej stronie.
Metafora

Wyobraź sobie, że ExpressJS to restauracja:🍽️

  • Klient przychodzi i pyta o menu:
    • nie chce niczego zamawiać, tylko zobaczyć, co jest dostępne.
    • to jest GET
  • Gdy klient składa zamówienie:
    • czyli przesyła dane, np. imię, adres, zamówienie
    • to jest POST.
  • Gdy usuwa rezerwację - to jest DELETE.
  • Gdy aktualizuje zamówienie - to jest PUT lub PATCH.

route parameter - parametr trasy​

route parameter

Parametr trasy to

  • nazwany segment URL,
  • pozwala na dynamiczne przechwytywanie wartości z adresu żądania.
  • jest definiowany za pomocą dwukropka : przed nazwą parametru w ścieżce trasy,
  • przechwycona wartość trafia do obiektu req.params w funkcji obsługi żądania.
app.get("/games/:id", (req: Request, res: Response) => {
    const game = games.find(g => g.id === Number(req.params.id));
    if (!game) return res.status(404).json({ message: "Game not found" });
    res.json(game);
});

i zapytanie:

### pytamy o grę z indeksem 3
GET {{baseUrl}}/games/3
Accept: application/json
Ważne

Express wartość zapisuje w req.params

  • dzięki temu możesz dynamicznie reagować na różne adresy,
  • np. /games/1 (id=1), /games/2 (id=2), itd.

Dodatkowe przykłady dla route parameter

app.get("/house/:name",(req: Request, res: Response) => {
    console.log(`req.params.name: ${req.params.name}`)
    res.send(req.params)
})

app.get("/house/:name/room/:number",(req: Request, res: Response) => {
   const {name, number} = req.params;
   console.log(`req.params: ${name}, ${number}`)
   res.send(req.params)
})

query parameter - parametr zapytania​

Co to są parametry zapytania (query parameters)
  • To dodatkowe informacje przekazywane w adresie URL po znaku ?,
  • Służą np. do
    • filtrowania,
    • wyszukiwania,
    • sortowania
    • ...

Przykład​

GET /games?year=1984&platform=Atari

? – zaczyna część parametrów zapytania
year=1984 – pierwszy parametr (klucz = wartość)
& – łączy kolejne parametry
platform=Atari – drugi parametr

Jak odczytać?​

Ważne

Express automatycznie umieszcza parametry zapytania w obiekcie 👉 req.query

Wybierzemy gry na Atarii wydane przed rokiem 1984​

Typ danych w req.query.platform
  • string
  • string[]
  • undefined

Możemy zagwarantować, że nasz platform to string przez typeof platform === 'string'

Do istniejącej app.get('/games' ... dodajemy:

app.get("/games", (req: Request, res: Response) => {
    const { year, platform } = req.query;

    // zwraca wszystkie gry, jeżeli nie podano year lub platform
    if(!year || !platform) return res.json(games)

   const filteredGames = games.filter(g => {
        if (year && g.year > Number(year))  return false

        if(platform){
            if (typeof platform === "string"){
                const queryPlatform = platform.toLowerCase();
                const gamePlatform = g.platform.toLowerCase();
                if(!gamePlatform.includes(queryPlatform)) return false;
            }
        }
        return true
    });

    res.json(filteredGames)
})
### filtrujemy gry po roku i platformie
GET {{baseUrl}}/games/?year=1984&platform=Atari
Accept: application/json

Różnica między rodzajami danych w Express​

Typ danychGdzie występujePrzykład URL / daneJak pobrać w Express
Route paramW ścieżce adresu (URL)/games/5req.params.id
Query paramPo znaku ? w adresie/games?year=1984&platform=Atarireq.query.year
Body paramW treści żądania (np. POST){ "title": "Pong" }req.body.title
tip

Opis:

  • Route param — używany do pobierania konkretnego zasobu (np. gry o danym id).
  • Query param — służy do filtrowania lub wyszukiwania danych.
  • Body param — wykorzystywany przy przesyłaniu danych do serwera (np. przy POST lub PUT).
